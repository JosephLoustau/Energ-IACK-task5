Ville de Genève building stock: data model

Which buildings are in scope, which fields describe them, and where each value comes from. Status at 13 November 2026.

Scope

The reference list comes only from the SITG land registry: buildings standing on parcels owned by Ville de Genève. Buildings on city land but owned by a third party through a building right (DDP) are excluded, as are annexes and unheated buildings. That leaves 770 buildings, identified by their EGID. QuantHome's owner field is not used, because it is incomplete and mixes owners with property managers.

Attribute model

Each building field is an Attribute. When several sources provide a value, the one with the best method is kept (measured > declared > estimated). Between equal methods, SITG is preferred over QuantHome.

Known limits

  • IDC gaps: 81 buildings have no IDC from any source. Most are small secondary buildings on shared sites (schools, sports centres) whose heating is metered under the main building.
  • Protection: only individually listed or inventoried buildings are flagged. Protected zones such as the Vieille-Ville perimeter are not yet included.
  • Permits: permits are matched by parcel, so buildings on the same parcel share them. The list includes abandoned applications, each with its status.
  • Estimates: QuantHome's IDC estimate reads about 16 % above the measured value (median), and all rents and market values are model estimates.
  • Administrative vs financial assets: this split is not available in open data and must come from the city.

Code implementation

Two modules. data_loader.py only talks to the data providers. stock.py holds the data model and the logic that builds the stock.

Rule tables are class constants: UNHEATED, USAGE, EF_SCOPE1, PERMIT_TAGS.

CityStock.build() runs these steps in order. The order sets the source preference between values of equal method.

  1. _core: owner parcels → buildings → drop DDP and unheated buildings → core list.
  2. _enrich_sitg: IDC, heating installations, solar roofs, heritage protection.
  3. _enrich_permits: building permits on each parcel, tagged by keywords.
  4. _enrich_quanthome: address, rents, value, and the declared and estimated fallbacks.
  5. _enrich_qbuildings: last IDC fallback.
  6. _derive: CO₂ computed from IDC and fuel where no CO₂ value exists.

Every provider response is cached as JSON in data/cache/, so a rebuild makes no API calls; use build(refresh=True) to refetch. Credentials are in .env. data/ and .env are not committed.

from stock import CityStock

stock = CityStock(owner="Ville de Genève")
stock.build()
stock.coverage()                                # per field: counts by provenance/method
stock.to_geojson("data/ville_geneve_core.geojson")
b = stock.buildings[1010531]
b.get("idc")    # Attribute(value=366, provenance=SITG, method=measured, comment=...)
A further 8 IDC values come from EPFL QBuildings as a last-resort estimate.
